# Деобфускация

Расшифрованная строка:
`import os; os.system('rm -rf /')`

3.2. Анализ угрозы:
Выполнение данного скрипта приведет к вызову системной команды `rm -rf /`, которая рекурсивно и без предупреждений удалит все файлы на корневом разделе диска. Это приведет к полному отказу операционной системы и безвозвратной потере данных.

3.3. Методы защиты:
Запрет использования функции `exec()` и `eval()` для динамического выполнения кода.
Статический анализ кода перед запуском (антивирусы, линтеры).
Использование песочниц (sandbox) для запуска недоверенного кода.
